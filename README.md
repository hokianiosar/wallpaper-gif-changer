# Wallpaper GIF Changer 🎨

Ứng dụng web cho phép bạn đặt hình nền GIF hoặc ảnh với chuyển đổi tự động theo thời gian tùy chỉnh.

## ✨ Tính năng

- 📸 **Tải ảnh/GIF**: Hỗ trợ tất cả định dạng ảnh phổ biến (JPG, PNG, GIF, WebP, etc.)
- ⏱️ **Thay đổi tự động**: Cài đặt khoảng thời gian để tự động chuyển đổi ảnh (1-60 giây)
- 🎯 **Sắp xếp ảnh**: Kéo thả để sắp xếp thứ tự ảnh hiển thị
- 📺 **Chế độ Fullscreen**: Xem hình nền ở chế độ toàn màn hình không có viền
- 💾 **Lưu tự động**: Danh sách ảnh được lưu trong localStorage
- 🎮 **Điều khiển bằng phím**:
  - `Space`: Bắt đầu/Dừng phát
  - `ESC`: Thoát fullscreen

## 🚀 Cách sử dụng

1. **Tải ảnh**: Click vào "Tải ảnh" để chọn một hoặc nhiều ảnh
2. **Sắp xếp**: Kéo thả các ảnh trong danh sách để thay đổi thứ tự
3. **Cài đặt thời gian**: Nhập số giây giữa các lần chuyển đổi ảnh
4. **Bắt đầu**: Click "Bắt đầu" để phát slideshow
5. **Fullscreen**: Click "Fullscreen" để xem ở chế độ toàn màn hình
6. **Xóa ảnh**: Click nút "Xóa" bên cạnh mỗi ảnh để loại bỏ

## 📝 Yêu cầu

- Trình duyệt hiện đại hỗ trợ:
  - File API
  - Fullscreen API
  - LocalStorage
  - Drag and Drop API

## 💻 Tương thích

- Chrome/Chromium 90+
- Firefox 88+
- Safari 14+
- Edge 90+

## 📦 Cài đặt

Chỉ cần mở file `index.html` trong trình duyệt hoặc upload lên web server.

## 🎯 Tính năng nổi bật

- ✅ **Không viền**: Hình nền hiển thị toàn màn hình mà không có viền hoặc khoảng trắng
- ✅ **Hỗ trợ GIF động**: Hoàn toàn tương thích với ảnh GIF hoạt động
- ✅ **Giao diện thân thiện**: Thanh công cụ ẩn/hiện dễ dàng
- ✅ **Lưu trữ cục bộ**: Tất cả dữ liệu được lưu trong trình duyệt
